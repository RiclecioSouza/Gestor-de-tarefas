# 📝 Gestor de Tarefas
Aplicação web para criação e organização de tarefas.

## 🚀 Funcionalidades
- ✅ Adicionar tarefas
- 🏷️ Categorizar tarefas
- 🔴 Definir prioridade
- 🔎 Pesquisar tarefas
- 🌙 Alternar entre tema claro e escuro
- 📊 Visualizar tarefas concluídas e pendentes

## 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript
- LocalStorage
